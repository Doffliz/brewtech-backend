# BrewTech — Інтернет-магазин кави (MVP)

Вебдодаток для кав'ярні «BrewTech», який включає каталог продукції, кошик, авторизацію та панель адміністратора.

## 🚀 Як запустити проект

1. Клонуйте репозиторій:


git clone <посилання-на-репозиторій>
Встановіть залежності та налаштуйте змінні середовища (.env).
Запустіть бекенд-сервер.
 Як зайти у панель адміністратора

Адмін-панель реалізована у вигляді окремої сторінки в проекті. Щоб потрапити до неї:

Запустіть локальний сервер або відкрийте фронтенд-частину застосунку.
У рядку браузера після адреси вашого локального сервера перейдіть за посиланням:
/admin.html

Наприклад:

http://localhost:3000/admin.html

або відповідно до вашого порту/хоста.

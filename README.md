# BrewTech — Інтернет-магазин кави (MVP)

Вебдодаток для кав'ярні «BrewTech», який включає каталог продукції, кошик, авторизацію та панель адміністратора.

## 🚀 Як запустити проєкт

1. Клонуйте репозиторій:
   
   git clone [https://github.com/Doffliz/brewtech-backend.git](https://github.com/Doffliz/brewtech-backend.git)

   Встановіть залежності та налаштуйте змінні середовища (.env).

   Запустіть бекенд-сервер.

🔐 Як зайти у панель адміністратора
Адмін-панель реалізована у вигляді окремої сторінки у проєкті. Щоб потрапити до неї:

1.Запустіть локальний сервер або відкрийте фронтенд-частину застосунку.

2. У рядку браузера після адреси вашого локального сервера перейдіть за посиланням:
 /admin.html Наприклад: http://localhost:3000/admin.html (або відповідно до вашого порту/хоста).

У панелі адміністратора ви зможете переглядати всі створені замовлення та керувати їхніми статусами в реальному часі.

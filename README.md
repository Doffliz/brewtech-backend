# BrewTech — Інтернет-магазин кави (MVP)

Вебдодаток для кав'ярні «BrewTech», який включає каталог продукції, кошик, авторизацію...

## 🚀 Як запустити проєкт

1. Клонуйте репозиторій:
```bash
git clone https://github.com/Doffliz/brewtech-backend.git
```

2. Перейдіть у папку проєкту та встановіть залежності:
```bash
cd brewtech-backend
npm install
```

3. Заповніть базу даних початковими даними (Seed):
```bash
npx ts-node src/seed.ts
```

4. Запустіть бекенд-сервер:
```bash
npm run dev
```

## 🔐 Як зайти у панель адміністратора

Адмін-панель реалізована у вигляді окремої сторінки у проєкті. Щоб потрапити до неї:

1. Запустіть локальний сервер командою `npm run dev`.
2. У рядку браузера перейдіть за таким посиланням:
```
http://localhost:3000/admin.html
```
(або відповідно до вашого порту/хоста).

У панелі адміністратора ви зможете переглядати всі створені замовлення та керувати їхніми статусами в реальному часі.

Важлива примітка щодо реєстрації (Supabase Auth)
Увага: У проєкті налаштовано інтеграцію з системою автентифікації Supabase. Реєстрація нових користувачів та подальший вхід успішно працюють тільки для реальних та підтверджених електронних пошт. Якщо вказати вигадану або непідтверджену пошту, система заблокує створення акаунта або видасть помилку валідації токена/API-ключів.

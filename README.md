# ☕ BrewTech System

Веб-застосунок та REST API для автоматизації замовлень у кав'ярні.

## 🚀 Технологічний стек
* **Backend:** Node.js, Express.js, TypeScript, Mongoose / MongoDB
* **Frontend:** Vanilla JavaScript, HTML5, CSS3

## 🛠 Інструкція із запуску
```bash
git clone [https://github.com/Doffliz/brewtech-backend](https://github.com/Doffliz/brewtech-backend)
cd brewtech-backend
npm install
npx ts-node src/seed.ts
npm run dev
